# Lean mathematics for R(3,3,3,3) ≤ 61

This package formalizes the mathematical reduction to **56,723 explicitly defined SAT formulas**. Lean proves exhaustive case coverage, preservation of one physical coloring under the coordinate changes, and satisfaction of the corresponding formulas by any hypothetical coloring without a monochromatic triangle.

The marked covers use normalized support-and-word configurations and one finite criterion: every retained target fact must pull back to a fact of the source configuration under a whole-host symmetry.

The endpoint is [`UniformK61.WholeProof.ramsey61`](src/UniformK61/WholeProof.lean):

```lean
ramsey61 (h : AllNativeUnsat) : ∀ c : Host, ¬NoMonochromaticTriangle c
```

`Host` is a four-coloring of all 61 vertices. The sole external premise, `AllNativeUnsat`, states that none of the indexed formulas has a satisfying valuation. No classification, case-coverage, transport or encoding assumption remains as a theorem parameter. The theorem's axiom audit contains only `propext`, `Classical.choice` and `Quot.sound`.

`WholeProof.native_case_count` proves this total. Every formula uses the same 7,320 physical edge-color variables and the same 156,770-clause good-coloring base on K61. The three balanced formulas additionally encode support choices and actual-neighborhood embeddings, giving 13,656 variables and 524,462 clauses each.

The source package includes 110 embedded classification files. The complete build includes the K15/K16 classification and replays its 55 CNF/LRAT pairs inside Lean. Native UNSAT results for the final formulas are external computational evidence. The input-binding checks connect their exact DIMACS bytes to the Lean definitions.

Lean 4.32.1 and Mathlib revision `520045ab14e26149ee970e2e617ca04b09bde5d6` are pinned. The source manifest identifies the complete dependency closure; compiled project artifacts are generated by the build.
